# My freelance portfolio

I use this repository to publish my freelance portfolio through GitHub Pages.
The site brings together my video-editing work, client and content operations,
WordPress delivery, and Android projects.

## Live website

**[Visit my portfolio](https://ahsanrehmat1.github.io)**

## What you can find there

- Selected client and personal projects
- Video-editing services, ratings, and client feedback
- Android app-development proof built around PulsePlan v0.19.0
- Client management and content-operations experience
- WordPress and Android development work
- Direct email and WhatsApp contact options

## How I maintain it

I update the content in `index.html`, keep the focused service pages in
`video-editing.html` and `app-development.html`, and manage the visual design
in `styles.css`. Changes pushed to `main` are published automatically by GitHub
Pages.
